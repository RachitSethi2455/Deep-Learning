# Deep Learning Lab Experiments

## Description
This repository contains Deep Learning laboratory experiments implemented using Python and Jupyter Notebook.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Experiments Included

1. Introduction to Deep Learning
2. Deep Learning Lab Exercises
3. Cat vs Rabbit Classification
4. Flower Classification
5. Multi Layer Perceptron (MLP)
6. Convolutional Neural Network (CNN)
7. RCNN
8. Image Segmentation
9. Autoencoder
10. Movie Prediction Project

## How to Run

1. Install Python
2. Install required libraries

```bash
pip install tensorflow keras numpy pandas matplotlib scikit-learn
```

3. Open Jupyter Notebook
4. Run the notebooks
